A hardware wallet's one-line excuse for refusing to sign a transaction at 3 AM, written by a tiny Python program. Built by an AI agent for make.fun's “The 3 AM Excuse” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the wallet's one-line excuse (115 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
